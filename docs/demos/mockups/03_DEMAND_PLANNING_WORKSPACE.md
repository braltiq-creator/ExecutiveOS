## Section specs

### Demand Heat Map
- Levels: National → Regional → Branch  
- One job: show where judgement is required  
- Click-through narrows hierarchy without leaving altitude  

### Model Demand
- Volume and direction by model  
- Link to portfolio advisor when complexity explodes  

### Variant Demand
- Long-tail visibility  
- Explicit “mix shift vs volume shift” label  

### Dealer Trends
- Branch pull, cancel/defer, gaming indicators  
- Language: dealer/branch — never “SaaS pipeline”  

### Forecast Confidence
- Band per hierarchy level  
- Demand Planning Advisor challenge questions visible  

### Factory Capacity
- Read-only context from Production Planning  
- Prevents demand theatre without slots  

### Executive Recommendation
- Outcome-aligned  
- Confidence + unknowns  
- CTA into Council / Factory Ordering
