# Workshop 16 — The First 15 Minutes

**Type:** Facilitated design workshop (founders)  
**Duration:** Suggested 90–120 minutes  
**Output:** Completed decisions in §12 (Workshop Outcomes)  
**Not in scope:** UX specs · wireframes · mock-ups · implementation · answering the questions in advance  

**Context (read beforehand, do not debate as the workshop):**  
Constitution · Core Executive Loop · Executive Experience Blueprint · Product Strategy v1 · Information Architecture · ADRs  

---

## How to run this workshop

1. Assign a **facilitator** (keeps time, does not win arguments) and a **scribe** (fills §12 only when the room agrees).  
2. Work sections **in order**. Do not skip to Magic Moment before personas and emotional state.  
3. Prefer **one primary persona** for the minute-by-minute pass; note deltas for the other two.  
4. When stuck, return to: *What requires my attention? Why? What should I do?*  
5. No wireframes. No feature lists. Capture **experience decisions** only.  
6. End only when §12 has explicit decisions — or explicit “undecided / needs follow-up” with an owner.
