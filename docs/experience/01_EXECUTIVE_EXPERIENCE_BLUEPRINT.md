## 1.2 Experience philosophy

### Today is not a workspace

Today answers only:

1. How healthy is my organisation?  
2. What changed?  
3. What needs my attention?  
4. Where should I go?  

It does **not** contain deep analysis, long narrative, evidence trees, or editing surfaces.

### Workspaces hold the work

| Workspace | Five-minute job |
|-----------|-----------------|
| Strategy | Direction and outcome health |
| Decisions | Judgment waiting and risk |
| Knowledge | Context, memory, customer signal |
| Reports | Value, narrative, board-ready output |
| Administration | System, people access, configuration |

### Three information levels

```
L1  Today          →  30 seconds   →  Awareness
L2  Workspace      →  5 minutes    →  Understanding
L3  Deep surface   →  30 minutes   →  Investigation
```

**Rule:** Never duplicate L2/L3 content inside Today.

---

## 1.3 Today as reference implementation

Every future screen must inherit from Today:

| Dimension | Today standard |
|-----------|----------------|
| Scan speed | Under 30 seconds for org state |
| Page scroll | Fixed viewport; only Activity Feed scrolls |
| Cards | EXS card system — identical padding, hover, focus |
| Icons | Permanent Lucide language |
| Colour | Semantic only (trend / risk / attention) |
| Copy | Chief of Staff — brief, actionable |
| CTA language | `Open →` / named module opens |
| Motion | Continuity (reveal, soft flash, page dive) |
| Return | Always back to Today as home |

If a proposed screen breaks any of these, it is not aligned.

## 1.4 Executive questions by surface

| Surface | Primary questions |
|---------|-------------------|
| Today | What’s true? What changed? What needs me? Where next? |
| Strategy | Are we winning? What’s off track? What should we reframe? |
| Decisions | What must I decide? What’s the risk of delay? |
| Knowledge | What do we know? What’s the customer/commercial signal? |
| Reports | What value did we create? What do we tell the board? |
| Administration | Is the system healthy? Who has access? What’s connected? |

## 1.6 Non-goals (this blueprint)

- Redesigning individual pages (Phase 36 is alignment only)  
- Changing Core engines, providers, routes, or data models  
- Adding new product features  
- Marketing site experience
