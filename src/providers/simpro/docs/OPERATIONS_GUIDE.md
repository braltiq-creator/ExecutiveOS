# Operations Guide

## Daily

- Confirm Sync Health = healthy
- Review retry queue depth
- Check overdue collections and critical jobs in Today Operational Context

## Weekly

- Renew webhook subscriptions
- Review margin-risk projects
- Rotate API keys / OAuth secrets per policy

## Incident

1. Inspect Errors panel
2. Replay from checkpoint / webhook journal
3. Run full sync if watermarks are corrupt
4. Disconnect only if credentials are compromised
