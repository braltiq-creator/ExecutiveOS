## Customer onboarding

Onboarding is **activation**, not “connect and forget.”

### Pre-start (Day 0)

| Step | Action |
|------|--------|
| 1 | Welcome + expectations + kickoff scheduled |
| 2 | Name sponsor (executive) and champion (CoS / EA / self) |
| 3 | Confirm package (Individual / Team / Enterprise) and **one Profile** |
| 4 | Provision organisation; invite seats as needed |
| 5 | Share short “first 10 minutes” orientation |

Self-serve customers use provisioning + Discovery; Design Partners receive white-glove.

### Kickoff (Day 1 — 45 minutes)

1. Vision: proactive intelligence, not another chatbot  
2. Tour: Command Centre → Strategy / Decisions → Council → Knowledge (as relevant)  
3. Discovery: role, three outcomes, briefing preference  
4. Optional: connect systems (M365 etc.) — never block first value on connectors  
5. Log first decision together  
6. Homework for Week 1  

**Day 1 success:** Sponsor has opened Command Centre; three outcomes exist; first decision logged.

## 30-day journey

| Window | Theme | Outcomes |
|--------|-------|----------|
| **Days 1–7** | Foundation | Outcomes set; initiatives or equivalent artifacts started; Command Centre shows ranked attention |
| **Days 8–14** | Rhythm | Sponsor opens Command Centre before first meeting ≥4 days in a week |
| **Days 15–21** | Judgement | Council / advisors used; pending decisions managed with rationale |
| **Days 22–30** | Proof | Self-reported time saved or decision clarity; trial → paid conversation |

### 30-day success criteria

- [ ] Weekly Active Executive habit forming (target trajectory toward ≥70% WAEx)  
- [ ] ≥1 decision logged with context  
- [ ] Profile still fits (or documented change request)  
- [ ] No open P0 blocking morning use  
- [ ] Clear path to Individual / Team / Enterprise conversion  

Trial commercial terms: [`02_PRICING_AND_PACKAGING.md`](./02_PRICING_AND_PACKAGING.md).

## 60-day journey

| Focus | Actions |
|-------|---------|
| **Deepen artifacts** | Decisions, initiatives, memory compounds |
| **Team picture** | If Individual, evaluate Executive Team when a second leader needs the same view |
| **Meeting rhythm** | Calendar-linked prep where connected |
| **Health review** | First formal health score conversation |
| **Expansion hypothesis** | Second Profile or Enterprise only when pain is real |

### 60-day success criteria

- [ ] WAEx stable or improving  
- [ ] Decisions and outcomes still current (not abandoned)  
- [ ] Champion can explain value in one sentence  
- [ ] NPS / pulse ≥30 trajectory

## 90-day journey

| Focus | Actions |
|-------|---------|
| **Executive review** | Formal session with economic buyer |
| **Case evidence** | Permission for anonymised or named story |
| **Renewal posture** | Annual option discussion |
| **Expansion** | Profile / Team / Enterprise motion if earned |
| **Referenceability** | Design Partner → case study path if applicable |

### 90-day success criteria

- [ ] WAEx ≥70% of enrolled executives (aspirational; align with beta metrics)  
- [ ] NPS ≥40 trajectory for healthy accounts  
- [ ] Documented outcomes moved or decisions accelerated  
- [ ] Expansion or renewal plan in writing

## Executive adoption

| Lever | Practice |
|-------|----------|
| **Morning ritual** | Command Centre before email — explicitly coached |
| **Low friction** | Proactive brief; avoid chat-first onboarding |
| **Champion** | CoS populates graph; executive consumes judgement |
| **Solo executive** | Individual package — shorter artifact set, same morning habit |
| **Anti-pattern** | Forcing every IC into the tool |

**Adoption definition:** Executive opens the intelligence surface ≥4 days/week and can name what required attention that morning.

## Health scores

Use product instrumentation where available; otherwise structured CS scoring.

| Signal | Healthy | At risk | Critical |
|--------|---------|---------|----------|
| **WAEx** | ≥70% | 40–69% | <40% |
| **Command Centre opens / week** | ≥4 | 2–3 | ≤1 |
| **Decisions logged (trailing 30d)** | Growing or steady | Flat after Week 2 | Zero |
| **Outcomes current** | Reviewed in 30d | Stale | Missing |
| **Sponsor engagement** | Attends reviews | Proxy only | Unreachable |
| **Support sentiment** | Calm | Frustrated | Escalating |

**Intervention:** At-risk → champion call within 5 days · Critical → executive sponsor call + reset plan.

## Expansion

| Signal | Offer |
|--------|-------|
| Second leader asks for access | Executive Team |
| New domain of judgement | Additional Profile / pack when SKU ready |
| Multi-entity / security / volume | Enterprise |
| Manufacturing depth proven | Manufacturing Profile narrative for peer BUs |

Never expand on fear. Expand on demonstrated clarity. See pricing doc.

---

## Renewals

| Timing | CS action |
|--------|-----------|
| **−90 days** | Value dossier: habit, decisions, outcomes, qualitative quotes |
| **−60 days** | Executive review + annual option |
| **−30 days** | Commercial confirm with Sales |
| **At risk** | Save plan: reset outcomes, reduce seats honestly, or Design Partner-style rescue — never fake usage |

Renewal is earned by **morning clarity**, not feature volume.

## Executive reviews

**Cadence:** Day 30 (light) · Day 60 · Day 90 · then quarterly for Team/Enterprise.

**Agenda (30 minutes):**

1. What required attention this period?  
2. Which decisions moved faster or with more confidence?  
3. What is still foggy?  
4. Profile fit and packaging  
5. One commitment for next period  

**Output:** Written summary in customer language; internal health score update; expansion/renewal flag.

## Relationship to Organisation Portal

Customers should manage subscription, security view, and systems from the Organisation Portal as product supports it. CS teaches Portal literacy — we do not become a permanent shadow admin for healthy accounts.
