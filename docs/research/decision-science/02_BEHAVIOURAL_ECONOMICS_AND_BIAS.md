## Purpose

Explain systematic judgement errors executives face and institutional counters.

---

## High-impact biases in the ELT

| Bias | Executive failure mode | Mitigation |
|------|------------------------|------------|
| Overconfidence | Narrow ranges; missed tails | Explicit confidence calibration; ranges |
| Confirmation | Seeking supportive data | Appoint a designated challenger |
| Sunk cost | Continuing failed bets | Kill criteria; stage gates |
| Anchoring | First number dominates | Independent estimates before discussion |
| Availability | Recent vivid events overweight | Base rates; structured KRIs |
| Optimism / planning fallacy | Heroic timelines | Reference-class forecasting |
| Groupthink | False consensus | Devil’s advocate; anonymous dissent |
| Loss aversion | Avoiding necessary writes/kills | Separate decision from ego |
| Attribution error | Blaming people not systems | Blameless + accountability for systems |

---

## Behavioural economics notes

- Prospect theory: losses loom larger than gains — affects pricing, write-offs, disclosure  
- Present bias: near-term pain avoided — fuels technical/operational debt  
- Social proof: competitors’ moves copied without advantage analysis  

---

## Bias mitigation design patterns

1. **Pre-mortem** before commit  
2. **Council structured dissent** by role lens  
3. **Decision journals** for learning  
4. **Red team** on material bets  
5. **Checklists** for recurring decision types  
6. **Separation** of option generation from evaluation  

---

## Implications for ExecutiveOS *(synthesis)*

Council roles encode lenses that counter common biases (e.g. CFO vs optimism; COO vs unbuildable plans). Validation rules should punish missing alternatives and unknowns under low confidence.
