# 10 — Product Roadmap (Commercial Lens)

**Version:** 1.0  
**Nature:** Commercial prioritisation of product direction — **does not invent features**  
**Engineering detail:** [`../business/ROADMAP.md`](../business/ROADMAP.md) · Architecture ADRs · Pack / Portal docs  
**Rule:** Outcomes over feature parity. Never contradict architecture (packs extend; Core stays stable).

---

## Roadmap principles

1. Ship what moves **habit** (WAEx), **clarity**, and **revenue conversion**  
2. Sell **Executive Intelligence** — Profiles and judgement quality over connector theatre  
3. Enterprise readiness is explicit — never ambush customers with missing trust surfaces  
4. Industry depth via **Intelligence Packs** (Manufacturing first) — not Core forks  
5. Label the future honestly  

---

## Release 1.0 — Executive Intelligence GA

**Commercial outcome:** Paying customers on Individual / Team; Enterprise path defined; Design Partners converting.

### In the commercial story (capabilities that exist or are GA-critical)

| Theme | Capability framing |
|-------|-------------------|
| **Daily altitude** | Command Centre / Executive Brief — proactive attention |
| **Operating loop** | Outcomes · Decisions · Knowledge · Strategy surfaces |
| **Judgement** | Executive Council / advisors; Models & Judgement Framework as platform intelligence |
| **Profiles** | Operations · Commercial · Manufacturing (one included per package) |
| **Industry** | Manufacturing Executive Intelligence Pack on EIPF |
| **Commercial SaaS** | Provisioning · Organisation Portal · trial → paid |
| **Trust** | Org isolation · security narrative · human authority |

### GA commercial priorities

- Public pricing aligned to AUD packaging ([`02_PRICING_AND_PACKAGING.md`](./02_PRICING_AND_PACKAGING.md))  
- Trial polish and upgrade path  
- Two case stories  
- Security page for procurement  
- Instrumentation for WAEx and conversion  

### Explicitly not the 1.0 headline

- Full autonomous executive agents  
- On-premise  
- Unlimited multi-profile portfolios (unless Enterprise custom and product-supported)  

**Success (commercial):** Paying logos · NPS trajectory · morning habit proof · Manufacturing reference narrative.

## Release 1.1 — Rhythm deepening

**Commercial outcome:** Higher retention and Team expansion; less “empty graph” churn.

| Priority | Direction (from existing product strategy / roadmap) |
|----------|------------------------------------------------------|
| **Persistence** | Advisor / assistant conversations that survive sessions |
| **Delivered brief** | Email or equivalent morning digest where roadmap delivers |
| **Calendar depth** | Richer meeting prep; additional calendar ecosystems as shipped |
| **Activation** | Faster time-to-first-value in Discovery / onboarding |
| **Quality** | Performance, reliability, observability for daily use |

**Sell as:** “The morning gets sharper every week — memory and rhythm compound.”

**Do not sell as:** New category pivot.

---

## Release 1.2 — Enterprise readiness

**Commercial outcome:** Credible Enterprise ACV; shorter security cycles.

| Priority | Direction |
|----------|-----------|
| **SSO / identity** | SAML (or equivalent) on Enterprise path as delivered |
| **Audit** | Event log for procurement |
| **Scale controls** | Rate limiting / caching as engineering delivers |
| **Support posture** | SLAs for Enterprise quotes |
| **Compliance journey** | SOC 2 engagement narrative only when factually true |

**Sell as:** “Executive Intelligence your CISO can diligence.”

Align claims to what has actually shipped — never ahead of engineering.

---

## Release 2.0 — Platform scale

**Commercial outcome:** Multi-BU Enterprise default; category leadership evidence.

| Priority | Direction (aligned to long-range product roadmap) |
|----------|-----------------------------------------------------|
| **Background intelligence** | Scheduled / proactive scans within product principles |
| **Delegation** | Follow-ups and CoS workflows as designed |
| **Conversation intelligence** | Meeting transcript → graph where delivered |
| **Ecosystem** | Webhooks / integration marketplace carefully |
| **Additional packs / profiles** | New industry context without Core customisation |
| **Compliance** | SOC 2 complete; residency options as available |

**Sell as:** “From daily Command Centre to executive operating platform.”

**Guardrail:** Autonomy advises and prepares; **executives decide**. Never market replacement of leadership accountability.
