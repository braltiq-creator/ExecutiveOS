# 03 — Website Blueprint

**Version:** 1.0  
**Purpose:** Complete information architecture for ExecutiveOS.com (or successor domain)  
**Design bar:** Apple clarity · Stripe trust · Linear restraint · Salesforce enterprise seriousness — without Salesforce visual noise  
**Aligns to:** Brand guidelines · Positioning Bible · Pricing · Experience System (light premium)

---

## Global rules

| Rule | Application |
|------|-------------|
| **Brand first** | Product name is a hero-level signal on branded pages |
| **One job per section** | One purpose, one headline, one short support line |
| **No dashboard theatre on marketing** | Product screenshots show calm Command Centre — not admin density |
| **CTA pair** | Primary: Start Free Trial · Secondary: Book a conversation / Watch demo |
| **Trust** | Security · human authority · explainability · customer logos only when earned |
| **Motion** | 2–3 intentional motions per page max — presence, not noise |
| **Never claim** | Features not in product; dark admin aesthetic; purple AI clichés |

**Primary CTA destination:** `/get-started` or Start Trial flow (Provisioning)  
**Secondary:** Sales conversation for Enterprise / Design Partner
