# Manufacturing Forecasting — Demonstration Dataset

**DEMONSTRATION DATA ONLY.** Not customer confidential. Not Hitachi confidential.

Synthetic dataset for ExecutiveOS Phase 59 Manufacturing Forecasting Intelligence.

## File

`demo-manufacturing-forecast.csv`

## Coverage

- 3 factories: Plant 1, Plant 2, Plant 3
- 5 regions: QLD, NSW, VIC, WA, SA
- 10 dealers
- 4 models: Model H, Model J, Model K, Model L
- 8 variants
- 12 monthly periods (2025-07 … 2026-06)

## Embedded demonstration patterns

These patterns exist so Forecasting Intelligence can surface evidence — they are not claims about any real organisation.

1. **QLD / NSW Model H acceleration** — actual demand above forecast
2. **WA Model J decline** — actual demand below forecast
3. **Model H overall outperform** — modest national uplift
4. **Variant H-XL inventory accumulation** — elevated inventory days + finished goods
5. **Plant 2 capacity pressure** — available slots tighten as Model H demand rises
6. **SA Model L forecast error** — widening actual vs forecast divergence
