# Executive Organisational Memory Engine

Preserves organisational experience so ExecutiveOS can recognise recurring situations,
recall previous decisions, and apply historical learning.

**Not** `src/lib/memory` (user memory records) or `src/intelligence/executive-memory` (EME).

## Isolation

Memory belongs only to the tenant. Never shared across customers.

## Today

`attachMemoryRecallToTodayActions` enriches recommendations with previous situations,
past decisions, observed outcomes, lessons, and similarity confidence.
