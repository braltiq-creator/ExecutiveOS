# 9. Executive Journeys

**Phase 36 · Experience Alignment**  

Every major workflow **begins at Today and ends at Today**.  
Today remains Command Centre; workspaces are temporary focus rooms.

---

## Journey template

```
Start: Today
  → Trigger (KPI / Priority / Feed / Pulse interpretation)
  → Workspace L2
  → [Optional L3]
  → Action / judgment
  → Return: Today
End: Today (updated awareness)
```

---

## 9.1 Morning orientation

| Step | Surface | Executive intent |
|------|---------|------------------|
| 1 | Today | Scan KPIs ≤10s |
| 2 | Today · Pulse | Read organisational mood |
| 3 | Today · Priorities | Note top 1–3 attention items |
| 4 | Today · Feed | Skim overnight movement |
| 5 | Today | Decide first drill — or stay |

**Success:** Oriented without leaving Today.  
**Return:** N/A (already home).

---

## 9.2 Outcome health check

| Step | Surface | Action |
|------|---------|--------|
| 1 | Today | Click **Organisation Health** or **Strategic Outcomes** |
| 2 | Strategy · Portfolio | Identify at-risk / watching outcomes |
| 3 | Strategy / Outcome L3 | Inspect movement and owners |
| 4 | Optional → Decisions | Open linked judgment if required |
| 5 | Today | Return via BrandMark |

**User outcome:** Know which outcomes need leadership this week.

## 9.11 Mid-day return loop

Executives leave Today open during meetings.

| Step | Surface | Action |
|------|---------|--------|
| 1 | Today | Background awareness |
| 2 | Workspace | Dive for a live question |
| 3 | Today | Return between topics |

**Success metric:** Today is the page that stays open all day.

---

## 9.12 Journey QA checklist

For each journey, verify:

- [ ] Starts at Today  
- [ ] Destination matches KPI/Priority contract  
- [ ] Icons consistent across steps  
- [ ] L3 has parent breadcrumb  
- [ ] Ends at Today  
- [ ] No L2/L3 content dumped onto Today  
- [ ] Copy remains Chief of Staff brief
