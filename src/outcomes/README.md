# Executive Outcomes Engine

Measures whether ExecutiveOS creates measurable business value.

**Not** the strategic Outcome Portfolio (`src/lib/outcomes` → `/outcomes`).
This engine powers **Administration → Outcomes**.

## Lifecycle

Recommendation: Generated → Viewed → Accepted → … → Confirmed → Archived  
Outcome: Open → Observed → Confirmed | Rejected

## Learning loop

Confirmed outcomes update overlay weights for Scenario Packs, validation confidence,
profile weighting, and Knowledge Graph weighting — without modifying Core engines.

## Isolation

Never compare customer business outcomes across tenants.
Portfolio reporting uses anonymised aggregates only.
