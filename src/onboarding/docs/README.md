# Executive Discovery Engine

Intelligent onboarding that learns the organisation from connected systems.

## Principles

1. Discover more than ask
2. Under 15 minutes to first Executive Briefing
3. Every discovery has confidence + evidence
4. Tenant isolation always
5. Corrections improve future inference

## Flow

Welcome → Minimum questions → Connect & discover → Validate → First Brief → Today
