# Snapshot Studio Migration

## For Design Partners

Send users to `/onboarding/snapshot` as the first product experience.

## For engineers

1. Do not add one-off upload UIs — use Snapshot Studio or UDG experience components.
2. Do not invent brief/council logic inside the studio — activate and launch.
3. Library entries are immutable; create a new snapshot instead of editing.
4. Command Centre remains `/today` (Mission Control).
