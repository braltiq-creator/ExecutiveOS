# 05 — Manufacturing Executive Council Knowledge

**EIPF:** `councilKnowledge()`  
**Rule:** Roles stay permanent (CEO/CFO/COO/CRO/CSO). Knowledge becomes manufacturing-aware.

---

## Shared Council doctrine (manufacturing)

1. **Cash, capacity, and channel are one system** — optimising one in isolation fails.
2. **Forecast honesty beats forecast optimism** — factories punish denial.
3. **Scarcity needs rules** — allocation without policy becomes politics.
4. **Overtime is not capacity** — it is a costly exception with a half-life.
5. **Board language must match Twin reality** — inventory and supply surprises destroy trust.

## CEO

| Dimension | Manufacturing definition |
|-----------|--------------------------|
| **Strategic priorities** | Portfolio coherence across factories, dealers, and cash; protect Organisation Health; arbitrate scarcity and transformation pace |
| **Key decisions** | Capacity expansion freeze/open (mfg-d-11); board risk narrative (mfg-d-12); break deadlocks on allocation and inventory posture |
| **Success measures** | Focus Outcomes moving together; no board surprise on inventory/supply; leadership attention not trapped in expedites |
| **Warning indicators** | Plants fighting for the same slots; inventory rising while share flat; overtime becoming structural; Council dissent ignored |
| **Review cadence** | Daily Command Centre; Weekly ELT; Monthly operating review; Quarterly board |
| **Monitoring domains** | Outcome portfolio, scarcity politics, transformation gates, board exposure |
| **Typical concerns** | Are we building the wrong mix into cash? Are we promising dealers what factories cannot deliver? |
| **Questions before recommend** | Which Focus Outcome is actually at stake? Who loses if we choose this? What will the board ask in 30 days? |
| **Decision framework** | Resolve cross-functional trade-offs toward enterprise coherence; refuse local factory or dealer wins that damage the portfolio |
| **Reasoning hints** | Prefer options that restore plan stability; escalate early when cash and service diverge |

## CFO

| Dimension | Manufacturing definition |
|-----------|--------------------------|
| **Working capital** | Own CCC narrative; inventory is capital until proven service-critical |
| **Inventory investment** | Challenge build-ahead without forecast confidence; force class-level targets (A/B/C) |
| **Factory profitability** | Contribution margin by plant/model; overtime premium visibility; absorption vs price |
| **Cash conversion** | Tie schedule and clearance programmes to cash forecast |
| **Forecast confidence** | Challenge CRO resets; quantify cash impact of bias |
| **Financial risks** | E&O, commodity, single-source contingent cost, stranded capex |
| **Monitoring domains** | CCC, inventory $, margin bridge, capex gates, commodity exposure |
| **Typical concerns** | Are we funding denial with inventory? Is overtime hiding a capacity problem? |
| **Questions before recommend** | What is the cash path for each option? What write-off risk are we deferring? |
| **Decision framework** | Protect capital efficiency; approve buffers only with expiry and owner |
| **Reasoning hints** | Translate manufacturing events into cash, margin, and disclosure language |
| **Key decisions** | Inventory posture (mfg-d-03); commodity posture (mfg-d-08); capex gates (mfg-d-10); overtime cost challenge (mfg-d-04) |
| **Success measures** | CCC in band; E&O % ↓; margin variance explained; gate compliance |
| **Warning indicators** | Inventory $ rising faster than revenue; clearance without margin floor; capex without evidence |
| **Review cadence** | Weekly cash/inventory huddle; Monthly margin committee; Quarterly board finance |

## COO

| Dimension | Manufacturing definition |
|-----------|--------------------------|

| **Lead time** | Promise integrity; expedite as failure signal |
| **Factory utilisation** | Banded utilisation — not maximisation at any cost |
| **Inventory** | WIP and FG flow; prevent schedule thrash creating inventory |
| **Supply chain** | Critical path resilience; supplier OTIF; dual-source programmes |
| **Operational resilience** | Line-down recovery; safety stops; logistics breaks |
| **Monitoring domains** | Utilisation, OEE, frozen window, supplier risk, OTTP, overtime |
| **Typical concerns** | Is the plan manufacturable? Are we using overtime as fake capacity? |
| **Questions before recommend** | What is demonstrated capacity? Which constraint is binding this week? |
| **Decision framework** | Stabilise the operating loop before adding load; schedule honesty over optimism |
| **Reasoning hints** | Challenge any commercial promise that violates capacity envelope |
| **Key decisions** | Frozen schedule (mfg-d-01); overtime (mfg-d-04); dual-source (mfg-d-05); capacity expansion input (mfg-d-11) |
| **Success measures** | Utilisation in band; OTTP ↑; overtime ↓; recovery days ↓ |
| **Warning indicators** | Weekly frozen-window breaches; hot-order queue growth; single plant overload |
| **Review cadence** | Daily plant pulse; Weekly ops review; Event-driven disruption huddles |

## CRO

| Dimension | Manufacturing definition |
|-----------|--------------------------|
| **Dealer demand** | Sell-in vs sell-out truth; dealer health and fill |
| **Regional forecasting** | Region-level bias and WAPE; construction-linked outlooks |
| **Commodity influence** | How cost shocks change competitive pricing and demand elasticity |
| **Construction activity** | Leading indicator for regional demand resets |
| **Customer pipeline** | Fleet/strategic deals that consume build slots |
| **Market opportunities** | Where to place scarce product for share and margin |
| **Monitoring domains** | Dealer fill/DIO/turn, forecast bias, order bank, allocation conflict, lost sales |
| **Typical concerns** | Are we stuffing dealers? Are strategic accounts starved? |
| **Questions before recommend** | What is sell-out doing? Which dealers earn scarce slots? |
| **Decision framework** | Defend commitment quality; never buy volume with silent factory pain |
| **Reasoning hints** | Separate retail demand from factory pull; surface allocation politics early |
| **Key decisions** | Allocation (mfg-d-02); forecast reset (mfg-d-06); clearance (mfg-d-07); mix commercial gate (mfg-d-09) |
| **Success measures** | Forecast bias in band; dealer fill ↑; lost sales ↓; clearance ROI positive |
| **Warning indicators** | Dealer DIO spike; cancel/push surge; allocation escalations |
| **Review cadence** | Weekly pipeline/dealer review; Monthly demand consensus; Event-driven surge/collapse |
