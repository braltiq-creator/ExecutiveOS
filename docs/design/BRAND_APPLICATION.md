# ExecutiveOS Brand Application

## Brand Extension Principles

Every touchpoint must feel like it comes from the **same intelligence office** — calm, precise, premium. When in doubt, remove elements.

---

## Website (Marketing)

| Element | Specification |
|---------|---------------|
| **Hero** | White canvas; Ink 900 headline; single Meridian mark; no stock photos |
| **Subhead** | Slate 600, 18px, max-width 560px |
| **CTA** | Primary "Request beta access" + secondary "Watch briefing demo" |
| **Social proof** | Logo strip desaturated 100%, opacity 60% |
| **Product shots** | Real Intelligence Center UI — light mode, anonymized data |
| **Typography** | Geist Sans; display 40px hero only |
| **Footer** | Ink 900 bg, white text, minimal links |

**Avoid:** Gradient meshes, floating 3D icons, "AI-powered" hero badge.

---

## Marketing Site Structure

```
Home → Product → Pricing → Security → Company → Request Access
```

Product page sections: Intelligence Center, Advisors, Graph, Calendar, Decisions — each one screenshot + three bullets.

## Conference Booth

| Element | Spec |
|---------|------|
| **Backdrop** | 2m wide; white; oversized wordmark; tagline below |
| **Demo** | 2 iPad Pro stations — Intelligence Center loop |
| **Print** | One-pagers at eye level; QR to beta request |
| **Swag** | Quality notebook (see merchandise) — no cheap pens |
| **Avoid** | Banner stands with stock photos, gimmicky AI visuals |

**Booth tone:** Quiet confidence. Conversation, not volume.

## Executive Reports (Export)

| Property | Spec |
|----------|------|
| Format | PDF, A4/Letter |
| Header | Ledger mark + org name + date |
| Typography | Serif optional for body (Georgia) — signals formality |

## Brand Compliance

| Violation | Severity |
|-----------|----------|
| Wrong logo colors | Critical |
| AI sparkle imagery | Critical |
| Comic Sans or off-brand fonts | Critical |
| Gradients on logo | High |
| Stock handshake photography | Medium |
| Exclamation marks in product | Medium |

**Review:** All external assets approved by CEO/founder during beta.
