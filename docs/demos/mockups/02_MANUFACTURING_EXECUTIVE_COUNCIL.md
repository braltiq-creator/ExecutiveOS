# Mockup 02 — Manufacturing Executive Council

**Type:** High-fidelity concept (documentation only)  
**Rule:** Permanent Council seats only — Domain Advisors appear as **contributors**, not members

---

## Layout

```
┌──────────────────────────────────────────────────────────────────────────┐
│  Executive Council · Manufacturing judgement                               │
│  Decision: West Model H fill vs Plant 2 capacity vs capital                │
├──────────────────────────────────────────────────────────────────────────┤
│  DOMAIN ADVISORS (specialists — not seats)                                 │
│  [Demand Planning] [Production] [Inventory] [Dealer] [Supply Chain] …      │
│  Each: evidence · challenge · confidence note                              │
├──────────────┬──────────────┬──────────────┬──────────────┬──────────────┤
│     CEO      │     CFO      │     COO      │     CRO      │     CSO      │
│  Enterprise  │   Capital    │  Operations  │  Commercial  │   Strategy   │
│  coherence   │   & cash     │  capacity    │  channel     │   mix        │
├──────────────┴──────────────┴──────────────┴──────────────┴──────────────┤
│  Consensus posture     Confidence band     Reasoning trail                 │
│  Dissent preserved (never collapsed to false unanimity)                    │
└──────────────────────────────────────────────────────────────────────────┘
```

---

## Council role cards (content cues)

| Role | Lens | Demo stance |
|------|------|-------------|
| **CEO** | Enterprise | One call — service without hidden capital cost |
| **CFO** | Capital | Cost overtime; release ageing capital |
| **COO** | Operations | Finite capacity; fatigue risk on overtime |
| **CRO** | Revenue / channel | Protect West strategic dealers |
| **CSO** | Strategy | Protect Model H; do not feed long-tail variants |

---

## Domain Advisor strip

For each advisor chip (expandable):

- **Observation** — what was monitored  
- **Challenge** — question put to Council  
- **Evidence** — systems / signals used  
- **Confidence** — drivers and unknowns  

**Label in UI chrome:** “Advises Council — not a Council member”

---

## Consensus · Confidence · Reasoning

| Block | Content |
|-------|---------|
| **Consensus** | Recommended posture in one paragraph |
| **Confidence** | Band + what would raise/lower it |
| **Reasoning** | Ordered trail: Advisors → Council → Recommendation |
| **Human authority** | “Council advises. You decide.” |

---

## Motion

1. Advisor chips settle before Council cards emphasise  
2. Confidence band fills calmly  
3. Dissent line fades in — never animated away
