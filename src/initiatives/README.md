# Strategic Initiative Engine

Coordinates strategic initiatives for the Executive Agenda.

- **Planner** — evidence-ranked initiatives from Council, Intelligence, Judgement, Foresight, Memory, Intent, Graph
- **Coordination** — every council member contributes; disagreement preserved
- **Dependencies** — cross-functional, capability, critical path, decision points, resources, assumptions, Business Events
- **Governance** — checkpoints, board cadence, Decision milestones, council triggers
- **Integration** — references Jira / SAP / Primavera / etc. without owning tasks

ExecutiveOS remains the executive coordination layer. Operational platforms execute.
