# ExecutiveOS Commercial Strategy Library

**Version:** 1.0  
**Owner:** Braltiq · Commercial  
**Status:** Canonical commercial operating manual  
**Nature:** Documentation only — synthesises existing product, architecture, and design foundations  
**Philosophy:** Confidence Through Clarity  

This library guides marketing, sales, customer success, design partners, website development, pricing, and long-term company growth. It does **not** invent product capability. Where product reality and commercial packaging diverge, the product remains source of truth for *what ships*; this library is source of truth for *how Braltiq sells and tells the story*.
